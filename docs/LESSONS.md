## 1. 每条教训必填字段

新建或改写教训时用下表（缺一不可）：

| 字段 | 含义 |
|------|------|
| **ID** | `L*` 协议/移植 · `C*` 协作/产品 |
| **标题** | 一句话 |
| **触犯记录** | 历次时间（可反复）；第一次 + 复发 |
| **内容** | 具体发生了什么（可复述的事实） |
| **损失 / 负面影响** | 已造成或差点造成的后果 |
| **新规则** | 对应 NORMS ID 或禁止/必须句 |
| **理由 / 原理** | 新规则为何能防再发（机制，非口号） |
| **源码 / log** | Outbound 路径 |

L* 与 C* 正文均已按上表字段书写（2026-08-07）。

## 4. 如何新增一条

1. 在 `LESSONS_RUST_PORT` 或 `LESSONS_SESSION_COLLAB` 按 §1 字段写全文。  
2. 本索引表加一行。  
3. 若升为 NORMS 规则：改 NORMS 并链本 ID。  
4. 写 `docs/logs/` 记当次收口。
